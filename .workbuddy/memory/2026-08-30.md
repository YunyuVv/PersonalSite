## 修复 React 19 script 标签警告
- 报错来源：`next-themes@0.4.6` 的 `ThemeProvider` 作为 Client Component 渲染了内联 `<script>`，React 19 / Next.js 16 会提示「Scripts inside React components are never executed when rendering on the client」。
- 解决：移除 `next-themes` 依赖，自实现 `src/components/theme-provider.tsx`（Client Component，提供 `useTheme` context，管理 localStorage 与系统主题监听，通过 `.dark`/`.light` class 切换）。
- 在 `src/app/layout.tsx` 的 `<head>` 中注入初始化脚本，在 React hydrate 前读取 localStorage 并设置 class，避免 FOUC；保留 `suppressHydrationWarning` 处理 hydration 差异。
- 进一步把内联脚本抽成 `public/theme-init.js` 外链，但 React 19 对 `<head>` 中的 `<script>` 标签仍会报警告，最终彻底移除 head 脚本。
- 最终方案：`layout.tsx` 不再注入任何 `<script>`；`theme-provider.tsx` 在首次客户端渲染时同步读取 `localStorage` 并应用 `.dark`/`.light` class，尽量减少 FOUC。`layout.tsx` 保留 `suppressHydrationWarning` 处理 hydration 差异。
- 更新 `theme-toggle.tsx`、`nav.tsx`、`home-hero-full.tsx` 的 `useTheme` 导入路径到 `@/components/theme-provider`。
- 从 `package.json` / `pnpm-lock.yaml` 移除 `next-themes@0.4.6`。
- 验证：`npm run build` 通过，lockfile 已清理，node_modules 中无 `next-themes` 残留。

## 修复 admin 本地按钮 hydration mismatch
- 报错：`Hydration failed because the server rendered HTML didn't match the client`，定位 `admin-form.tsx:349` 的 `{isLocal && <button>仅更改本地文件</button>}`。
- 根因：`isLocal` 在服务端为 `false`（无 `window`），客户端为 `true`（localhost），导致 SSR 与客户端 DOM 结构不一致。
- 解决：引入 `mounted` 状态（`useEffect` 在客户端挂载后置 `true`），按钮条件改为 `{mounted && isLocal && ...}`，确保首次服务端/客户端渲染输出一致。
- 验证：`npm run build` 通过。

## 修复暗黑模式刷新白闪（FOUC）—— 最终恢复 next-themes
- 排查发现：原 PersonalSite-home（f22e5b4 初始化）与参考项目 `/Users/wangpenglong/projects/nextjs/PersonalSite` 都直接用 `next-themes@0.4.6`，它会在 `<head>` 自动注入**阻塞式内联脚本**设好 `.dark`/`.light` class，原本"不闪、也不报 React 19 script 警告"。白闪是我移除 next-themes 自实现、又尝试 `next/script beforeInteractive` 失败后引入的。
- 关键坑：`next/script` 的 `beforeInteractive` 在 App Router + React 19 下**不可靠**——内联内容被序列化成 RSC flight 数据（`self.__next_s.push(...)`），外部 src 仅生成 `<link rel=preload>` 不执行，均无法在 hydration 前生效，所以既报过警告又导致白闪。
- 最终修复：恢复 `next-themes`（pnpm add next-themes@0.4.6）；`theme-provider.tsx` 改为封装 `next-themes` 的 ThemeProvider 并 `export { useTheme } from "next-themes"`（消费方 nav/theme-toggle/home-hero-full 的 import 路径不动）；`layout.tsx` 改用 `attribute="class" defaultTheme="system" enableSystem disableTransitionOnChange`；删除无用的 `public/theme-init.js` 与 `next/script` 引用。
- 验证：build 通过；HTML 中确认 next-themes 注入真实可执行阻塞脚本（`localStorage.getItem theme` + matchMedia 解析），且 `__next_s` RSC 形式消失。暗黑刷新白闪应彻底消失，且不触发 React 19 script 警告。
