## 修复 MaskedHeading 显示为整块渐变条
- 用户反馈首页 "YunYu" 区域显示成一整条渐变矩形，没有按文字裁剪。
- 根因：在 `src/components/reactbits/masked-heading.tsx` 中添加 `background` 属性时，不慎把原组件里承载 `clipPath: url(#id)` 的中间 `<span>` wrapper 删掉了，导致媒体层完全没被 clipPath 裁剪。
- 修复：恢复中间 wrapper `<span className="absolute inset-0 block" style={{ clipPath: \`url(#${clipId})\` }}>`，把 `mediaRef`（含 background/src）重新包在里面。
- 验证：`pnpm run build` 通过。
