## 通用适配规范

所有从 reactbits.dev 集成的组件，统一遵循以下项目约定：

```tsx
"use client";                    // App Router 必须
export function ComponentName()  // named export，不用 default export
useReducedMotion()               // 无障碍：系统/用户关闭动画时回退静态背景
aria-hidden="true"               // 装饰性背景对屏幕阅读器不可见
pointer-events-none              // 默认不拦截鼠标事件（交互组件例外）
className prop                   // 支持外部 Tailwind 类覆盖
```

文件统一放在 `src/components/reactbits/` 目录下，文件名为 kebab-case。

### 依赖说明

| 组件 | WebGL 库 | 安装命令 |
|------|----------|----------|
| FloatingLines | three.js | `pnpm add three @types/three` |
| SideRays | ogl | `pnpm add ogl` |
| LightRays | ogl | `pnpm add ogl` |

ogl 自带 TypeScript 类型（`ogl/types/index.d.ts`），无需额外安装 @types。

## FloatingLines

**来源**: [reactbits.dev/backgrounds/floating-lines](https://www.reactbits.dev/backgrounds/floating-lines)
**WebGL 库**: three.js (Scene + OrthographicCamera + ShaderMaterial)
**文件**: `floating-lines.tsx`

### 基本用法

```tsx
import { FloatingLines } from "@/components/reactbits/floating-lines";

<FloatingLines
  linesGradient={["#6b8cff", "#7c5cff", "#ff6b8c"]}
  lineCount={8}
  lineDistance={8}
  animationSpeed={0.8}
  interactive
  bendRadius={8}
  bendStrength={-2}
/>
```

### Props

| Prop | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| linesGradient | string[] | - | 渐变色数组，hex 格式，最多 8 个 |
| enabledWaves | Array<"top" \| "middle" \| "bottom"> | 全部 | 启用哪些波浪层 |
| lineCount | number \| number[] | [6] | 每层线条数 |
| lineDistance | number \| number[] | [5] | 线条间距 |
| animationSpeed | number | 1 | 动画速度倍率 |
| interactive | boolean | true | 是否开启鼠标弯曲交互 |
| bendRadius | number | 5.0 | 鼠标弯曲影响半径 |
| bendStrength | number | -0.5 | 鼠标弯曲强度 |
| mouseDamping | number | 0.05 | 鼠标阻尼（0-1，越小越灵敏） |
| parallax | boolean | true | 是否开启视差效果 |
| parallaxStrength | number | 0.2 | 视差强度 |
| mixBlendMode | CSSProperties["mixBlendMode"] | "screen" | CSS 混合模式 |
| className | string | "" | 自定义 className |

### 注意事项

1. **useEffect 依赖数组使用序列化值**：GLSL uniform 引用的数组（如 linesGradient）在依赖中用 `.join(",")` 而非直接引用，避免每次渲染因引用变化导致 WebGL context 重建。
2. **interactive 与 pointer-events 的关系**：`interactive=true` 时容器不加 `pointer-events-none`，否则鼠标事件无法到达 canvas。详见踩坑记录。
3. **WebGL 清理**：组件卸载时调用 `renderer.forceContextLoss()` 和 `dispose()` 释放 GPU 资源。

## SideRays

**来源**: [reactbits.dev/backgrounds/side-rays](https://www.reactbits.dev/backgrounds/side-rays)
**WebGL 库**: ogl (Renderer + Program + Triangle)
**文件**: `side-rays.tsx`

### 基本用法

```tsx
import { SideRays } from "@/components/reactbits/side-rays";

<SideRays
  rayColor1="#EAB308"
  rayColor2="#96c8ff"
  intensity={2}
  spread={2}
  origin="top-right"
/>
```

### Props

| Prop | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| speed | number | 2.5 | 动画速度 |
| rayColor1 | string | "#EAB308" | 光线颜色 1 (hex) |
| rayColor2 | string | "#96c8ff" | 光线颜色 2 (hex) |
| intensity | number | 2 | 光线亮度 |
| spread | number | 2 | 光线展开角度 |
| origin | "top-right" \| "top-left" \| "bottom-right" \| "bottom-left" | "top-right" | 光线出发点 |
| tilt | number | 0 | 倾斜角度（度） |
| saturation | number | 1.5 | 饱和度 |
| blend | number | 0.75 | 两束光线混合比 (0-1) |
| falloff | number | 2.0 | 衰减指数 |
| opacity | number | 1.0 | 整体不透明度 |
| className | string | "" | 自定义 className |

### 注意事项

1. **懒初始化**：使用 IntersectionObserver，仅在组件可见时才初始化 WebGL 上下文，减少不可见区域的 GPU 开销。
2. **实时 uniform 更新**：有独立的 useEffect 监听 prop 变化，直接修改 uniform 值，无需重建 WebGL 场景。
3. **始终 pointer-events-none**：SideRays 是纯装饰效果，不需要鼠标交互，始终保持 pointer-events-none。

## LightRays

**来源**: [reactbits.dev/backgrounds/light-rays](https://www.reactbits.dev/backgrounds/light-rays)
**WebGL 库**: ogl (Renderer + Program + Triangle)
**文件**: `light-rays.tsx`

### 基本用法

```tsx
import { LightRays } from "@/components/reactbits/light-rays";

<LightRays
  raysOrigin="top-center"
  raysColor="#ffffff"
  raysSpeed={1}
  lightSpread={1}
  followMouse
  mouseInfluence={0.1}
/>
```

### Props

| Prop | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| raysOrigin | RaysOrigin | "top-center" | 射线出发点（8 个方向） |
| raysColor | string | "#ffffff" | 射线颜色 (hex) |
| raysSpeed | number | 1 | 动画速度 |
| lightSpread | number | 1 | 光线展开度 |
| rayLength | number | 2 | 光线长度倍率 |
| pulsating | boolean | false | 是否脉冲闪烁 |
| fadeDistance | number | 1.0 | 淡出距离倍率 |
| saturation | number | 1.0 | 饱和度 |
| followMouse | boolean | true | 是否跟随鼠标 |
| mouseInfluence | number | 0.1 | 鼠标影响力 (0-1) |
| noiseAmount | number | 0.0 | 噪点量 |
| distortion | number | 0.0 | 扭曲量 |
| className | string | "" | 自定义 className |

### 注意事项

1. **鼠标追踪**：followMouse 通过 window 级别的 mousemove 事件实现，使用平滑插值（smoothing=0.92）避免抖动。
2. **与 SideRays 的区别**：LightRays 支持 8 个出发点、鼠标跟随、脉冲、噪点、扭曲等更多参数；SideRays 只有 4 个出发点但双色光束更鲜明。
3. **followMouse 需要事件穿透**：如果 LightRays 在 z-index 较低的背景层，上层内容需要 `pointer-events-none` 才能让鼠标追踪生效。

## 踩坑记录

### 1. 鼠标交互失效：pointer-events 层叠遮挡

**现象**: FloatingLines 的鼠标弯曲交互不生效，移动鼠标无任何反应。

**原因**: 两层问题叠加。

第一层——组件自身：适配时按项目惯例给容器加了 `pointer-events-none`，阻止鼠标事件到达 WebGL canvas。

```tsx
// ❌ 错误：interactive 时也阻止了事件
className="... pointer-events-none"

// ✅ 正确：interactive 时允许事件穿透
className={`... ${interactive ? "" : "pointer-events-none"}`}
```

第二层——页面布局：demo 页面的内容覆盖层（z-10）覆盖了整个屏幕，所有鼠标事件被内容层拦截。

```tsx
// ❌ 错误：内容层拦截所有鼠标事件
<div className="relative z-10 flex flex-col min-h-screen">

// ✅ 正确：内容层穿透，交互元素单独恢复
<div className="relative z-10 flex flex-col min-h-screen pointer-events-none">
  <header className="... pointer-events-auto">  {/* Tab 按钮 */}
  <div className="...">                          {/* 中心标题，穿透 */}
  <div className="... pointer-events-auto">      {/* 控制面板 */}
```

**教训**: WebGL 交互组件作为背景时，所有覆盖在上方的层必须 `pointer-events-none`，仅需要点击的元素恢复 `pointer-events-auto`。

### 2. 获取 reactbits 源码：WebFetch 无法提取

**现象**: 用 WebFetch 访问 reactbits.dev 页面，返回的内容几乎没有组件源码（被 JS 动态渲染）。

**解决**: 直接 clone GitHub 仓库获取源码。

```bash
git clone --depth 1 https://github.com/DavidHDev/react-bits.git /tmp/react-bits-temp
```

源码位于 `src/ts-tailwind/Backgrounds/` 目录下，每个组件有独立的 `.tsx` 文件和可选 `.css`。

### 3. TypeScript 检查的报错干扰

**现象**: 直接 `npx tsc --noEmit file.tsx` 会报 JSX 和路径别名错误。

**解决**: 必须使用项目 tsconfig：

```bash
npx tsc --noEmit --project tsconfig.json
```

开发服务器缓存可能产生无关报错（如 `.next/dev/types/validator.ts` 引用已删除的页面），忽略即可。

### 4. 端口配置

项目 dev 端口已在 `package.json` 中配置为 12002：

```json
"dev": "next dev -p 12002"
```

直接 `pnpm run dev` 即可，无需手动指定端口。Demo 页面地址：`http://localhost:12002/demo`

### 5. ogl vs three.js 选型

FloatingLines 原始代码使用 three.js（Scene + OrthographicCamera + PlaneGeometry + ShaderMaterial），体积较大但功能完整。

SideRays 和 LightRays 使用 ogl（Renderer + Program + Triangle），体积小得多（~15KB gzipped vs three.js 的 ~150KB），适合简单的全屏 shader 场景。

两者共存不会冲突，但如果未来所有背景都迁移到 ogl，可以考虑移除 three.js 依赖来减小包体积。

### 6. Demo 页面三合一架构

`/demo` 页面通过 Tab 切换展示三个组件，每个 Tab 共享同一个全屏背景区域和独立的控制面板。关键结构：

```
z-0: 固定全屏背景（根据 tab 切换渲染不同组件）
z-10: 内容覆盖层（pointer-events-none 穿透）
  ├── header (pointer-events-auto) — Tab 切换
  ├── center (穿透) — 标题/标签
  └── controls (pointer-events-auto) — 参数滑块/按钮
```
