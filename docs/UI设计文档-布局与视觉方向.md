### 一、整体视觉方向

**风格关键词：** 随性但有趣、技术感、暗色优先、动效驱动

当前站点以暗色模式为主视觉基调，LightRays 光柱从顶部倾泻而下，营造舞台聚光灯的感觉。整体排版追求"呼吸感"——大面积留白配合精准点缀的动效，让技术服务于氛围而非喧宾夺主。

**字体体系：**
- 中文显示：系统默认（苹方/思源黑体）
- 英文 Display：Bricolage Grotesque（creative 页）或系统 sans-serif
- 等宽辅助：Space Mono（标签、代码、元信息）

**色彩体系（基于 CSS 变量，已有）：**
- 主背景：`--bg-primary`（深色模式近黑，浅色模式近白）
- 强调色：`--accent`（蓝色系 #5b8def）
- 文字层次：`--text-primary` / `--text-secondary` / `--muted`
- reactbits 组件色彩跟随主题变量，深色模式下 WebGL 效果更突出

**简历页核心交互：**

- **Silk 背景：** 极低透明度（0.08-0.12），仅暗色模式可见，给整个页面增加微妙的流动感，不影响卡片内容可读性
- **CountUp 数字：** 进入视口时从 0 滚动到目标值，动画时长 2s，使用 ease-out 缓动
- **MagicBento 技能：** 每个技能卡片有微弹跳入场，hover 时轻微放大 + 阴影增强
- **ScrollStack 经历：** 随页面滚动，经历卡片依次从底部推入并堆叠，最新经历在最上层
- **TiltedCard 项目：** 鼠标在卡片上移动时，卡片沿 X/Y 轴倾斜，最大倾斜角 15°，同时显示光泽反射
- **SpotlightCard 关于：** 鼠标位置产生圆形追光，照亮卡片内的文字和图标

**创意页核心交互：**

- **LetterGlitch 背景：** 字符矩阵以极低透明度（0.05-0.08）覆盖全页，字符缓慢随机变化，偶尔整行 glitch 抖动。不影响内容阅读，但增加"黑客感"氛围
- **TextPressure 标题：** 鼠标靠近大号标题时，字形根据距离产生挤压/拉伸变形，创造有趣的物理感
- **Magnet 按钮：** CTA 按钮在鼠标靠近（约 100px 范围）时被磁性吸引，跟随鼠标偏移
- **CardSwap 作品：** 项目以堆叠卡片展示，点击或拖拽可将顶部卡片甩到后方，露出下一张
- **BlobCursor 光标：** 鼠标变为液态粘性光斑，移动时有延迟和弹性变形（仅暗色模式，浅色模式降级为默认光标）
- **OrbitImages：** 技术图标（React/Docker/Cloud 等）以圆形轨道环绕鼠标当前位置缓慢旋转

### 七、全局视觉规范

**7.1 动效密度控制**

每屏可见区域内不超过 2 个同时运行的 WebGL 动效。文字类动效（SplitText、DecryptedText 等）属于轻量级，不受此限制。原则是让用户的注意力有焦点——背景是氛围，前景是内容，中间层动效是桥梁。

**7.2 动效触发策略**

| 类型 | 触发方式 | 时长 | 缓动 |
|------|---------|------|------|
| 入场动画（SplitText 等） | 页面加载 / 进入视口 | 0.5-1.5s | ease-out |
| 循环动画（ShinyText、LogoLoop） | 持续运行 | 无限 | linear |
| 交互动画（GlareHover、TiltedCard） | 鼠标悬停 | 即时响应 | ease-in-out |
| 滚动动画（ScrollVelocity、ScrollStack） | 页面滚动 | 跟随滚动 | — |
| 背景动画（LightRays、Silk、Aurora） | 持续运行 | 无限 | linear |

**7.3 Reduced Motion 降级策略**

当用户系统开启 `prefers-reduced-motion` 时，所有 reactbits 组件降级为静态展示：WebGL 停止渲染显示静态帧或纯色，文字动效跳过动画直接显示最终状态，滚动动效改为简单 fade-in。

**7.4 深浅模式适配**

| 组件 | 浅色模式 | 深色模式 |
|------|---------|---------|
| LightRays | opacity 60%, 蓝色调 | opacity 90%, 白色光 |
| Silk | 不显示 / opacity 5% | opacity 8-12% |
| Aurora | 不显示 / opacity 5% | opacity 10-15% |
| LetterGlitch | opacity 3% | opacity 5-8% |
| ElectricBorder | 深色强调色 | 亮色强调色 |
| BlobCursor | 禁用 | 启用 |
| SpotlightCard | 微弱追光 | 明显追光 |

**7.5 响应式断点**

| 断点 | 布局调整 |
|------|---------|
| `< 640px` (sm) | 单列布局，WebGL 背景降低分辨率，CardSwap 替代 TiltedCard |
| `640-1024px` (md) | 两列 Bento Grid，正常动效 |
| `> 1024px` (lg) | 完整布局，所有动效启用 |
| `> 1280px` (xl) | 最大宽度 1280px 居中，两侧留白 |

**7.6 页面间过渡**

推荐在第二期引入 PixelTransition 组件作为页面切换过渡效果。过渡时长 400ms，像素化溶解当前页面并展现下一页。在过渡未完成前禁止用户交互。
