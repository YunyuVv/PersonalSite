# 个人站点 — 需求文档（首页 + 简历子页 · 多页架构）

> 版本：v3.0  
> 最后更新：2026-07-24  
> 设计依据：ui-ux-pro-max skill 设计数据库（Soft UI Evolution / Bento Grid 模式、配色与字体检索结果）

---

## 1. 项目重新定位

### 1.1 一句话定义

> **一个"个人主页 + 简历子页"的双层个人站点**——首页是让人想点进来的门户，简历页是让人看完了想联系的完整履历。两者共享一套设计语言，但各司其职。

### 1.2 核心问题

上一版（v2.0）把整站压成一个"国风数字简历"单页，虽然惊艳但有两个问题：
1. **入口即终局**：打开就是满屏简历，缺少一个轻量、友好的"门面"让人先建立好感。
2. **信息密度一刀切**：HR 想要 30 秒概览，深度候选人想要完整履历，单页只能折中。

v3.0 拆成两层：

```
┌─────────────┐   点击"查看简历"   ┌──────────────────┐
│  首页        │ ─────────────────▶ │  简历子页 (/resume)│
│  (门户/门面) │                    │  (完整履历 Bento)  │
│  轻量·好感   │ ◀───────────────── │  深度·专业         │
└─────────────┘   返回首页          └──────────────────┘
```

### 1.3 目标用户

| 用户角色 | 首站触点 | 核心诉求 |
|---------|---------|---------|
| 初次访客 / HR | 首页 | 3 秒内知道"这是谁、值不值得看" |
| 技术面试官 | 首页 → 简历页 | 快速判断技术栈匹配度与工程品味 |
| 团队 Leader | 简历页 | 感受审美、项目经验、执行力 |
| 同行开发者 | 首页 → 简历页 | "这哥们站点有点东西" |

### 1.4 成功指标

- 首页平均停留 > 20 秒，简历页平均停留 > 40 秒
- 首页 → 简历页 跳转率（进入简历的比例）> 35%
- 移动端（375px）体验不打折

## 2. 信息架构（多页）

整个站点 3 条路由，全部 SSG 静态生成，无后端：

| 路由 | 页面 | 定位 | 视觉风格 |
|------|------|------|---------|
| `/` | 个人主页（Home） | 门户/门面，轻量好感 | Soft UI Evolution（单色+蓝点缀，留白足）|
| `/resume` | 个人简历（Resume） | 完整履历，深度专业 | Bento Grid 苹果风（沿用 v2 已实现）|
| `/creative` | 互动版（可选） | 创意实验场，从首页/简历页可跳 | 深墨+紫/珊瑚双色渐变（已存在）|

> 迁移说明：v2 的 Bento 简历当前在 `/`，重构后**整体迁移到 `/resume`**，`/` 让位给新的首页。

## 3. 设计语言（风格与色彩）

### 3.1 设计哲学

- **统一令牌，分层表达**：首页与简历页共用一套 CSS 变量设计令牌（颜色/字体/间距/圆角/阴影），保证全局一致性；首页偏"轻盈门面"，简历页偏"信息密度"。
- **Soft UI Evolution（首页主风格）**：演化版柔和 UI——比扁平多一点层次、比新拟物更克制；更好的对比度、现代审美、无障碍友好。浅色/深色双模式完整支持。
- **苹果蓝点缀**：强调色统一为苹果蓝（见 3.3），克制使用（CTA、链接、hover 描边），不堆砌。
- **动效服务叙事**：仅滚动触发、150–300ms、尊重 `prefers-reduced-motion`；不做纯装饰动画。

### 3.2 字体体系

| 用途 | 字体 | 来源 | 说明 |
|------|------|------|------|
| 首页大标题（display）| Space Grotesk | Google Fonts | 设计师/作品集气质，区别于简历页，建立门户个性 |
| 正文 / UI / 简历页 | Inter | Google Fonts / `next/font` | 开发者专业、干净、可读性高 |
| 等宽（标签/数据）| JetBrains Mono | Google Fonts | 技能标签、技术名词 |
| 中文 | 系统字体栈（PingFang SC / Microsoft YaHei）| 系统 | 不额外引中文字体，控体积 |

> 首页用 Space Grotesk 做大标题，与简历页的纯 Inter 形成"门面 vs 文档"的微妙区隔，但正文统一 Inter，整体仍连贯。

### 3.3 色彩体系（统一令牌）

基于 ui-ux-pro-max 检索的 "Monochrome + blue accent" 方案，与现有苹果蓝对齐：

| 角色（token） | 浅色值 | 深色值 | 用途 |
|------|------|------|------|
| `--bg-primary` | `#FAFAFA` | `#0B0B0F` | 页面主背景 |
| `--bg-card` | `#FFFFFF` | `#161618` | 卡片/面板背景 |
| `--text-primary` | `#18181B` | `#FAFAFA` | 主文字 |
| `--text-secondary` | `#52525B` | `#A1A1AA` | 辅助文字 |
| `--accent`（苹果蓝）| `#2563EB`* | `#5B8DEF` | CTA、链接、hover 描边 |
| `--border` | `#E4E4E7` | `#27272A` | 分割线、卡片边框 |
| `--muted` | `#E8ECF0` | `#1F1F22` | 弱背景区、占位 |
| `--ring` | `#18181B` | `#FAFAFA` | 键盘焦点环 |

> *`#2563EB`（Tailwind blue-600）与现有 `#3b5ccc` 苹果蓝高度接近；为减少重构，可沿用现有 `--accent` 值，二者皆可。统一以单一 `--accent` 令牌控制。

**深浅模式**：两套变量在 `:root` 与 `.dark` 下切换，全站元素（含首页与简历页）均引用变量，无硬编码色值。

### 3.4 视觉元素与质感

| 元素 | 说明 |
|------|------|
| 卡片 | 圆角 16–24px，1px 边 `--border`，柔和阴影（非新拟物）；hover 轻微抬升 + 描边变蓝 |
| 标签 chips | 技能/技术标签用圆角胶囊，hover 蓝边 |
| 图标 | 一律 SVG（Lucide），**禁用 emoji 作图标** |
| 焦点态 | 所有可点击元素 `focus-visible` 可见焦点环（键盘可达）|
| 光晕 | 极淡顶部径向光晕（替代廉价浮动光斑），不喧宾夺主 |

### 3.5 动效原则

- 触发：滚动进入视口（IntersectionObserver / framer `whileInView`）
- 时长：150–300ms（入场 stagger 300–450ms，`back.out(1.4)` 缓动）
- 降级：`prefers-reduced-motion` 下所有非必要动画直出最终态
- 属性：仅动画 `transform` / `opacity`（GPU 友好），禁动画 `width/height`

## 4. 首页（个人主页）详细设计

### 4.1 定位

轻量、友好、有记忆点的"门面"。目标是让访客在 3 秒内建立好感，并自然导向简历页 / 项目 / 联系。

### 4.2 页面结构（自上而下）

```
┌──────────────────────────────────────┐
│  Nav（首页导航：关于/作品/简历/联系）   │  ← 毛玻璃固定栏
├──────────────────────────────────────┤
│  #1 Hero / 自我介绍                    │  ← 姓名 + 角色 + 一句话 + 头像/字母 monogram
│       主 CTA：查看简历 / 联系我         │
├──────────────────────────────────────┤
│  #2 关于（一句话哲学）                  │  ← 短自述（2-3 行）+ 现居地/状态徽章
├──────────────────────────────────────┤
│  #3 精选作品（Featured）               │  ← 3 张项目卡（外链）+ "看全部简历"入口
├──────────────────────────────────────┤
│  #4 能力速览（Skills 速览）            │  ← 分类 chips（不展开完整雷达，留给简历页）
├──────────────────────────────────────┤
│  #5 快速链接（Link tree 风格）          │  ← 简历 / GitHub / 社交 / 外部博客
├──────────────────────────────────────┤
│  #6 联系 CTA（Footer 区）              │  ← 邮箱复制 + 社交图标 + "一起做点什么？"
└──────────────────────────────────────┘
```

### 4.3 各区块要点

- **Hero**：大字号姓名（Space Grotesk display）+ 角色定位 + 一句话 tagline + 头像或字母 monogram 圆形；双 CTA（主：查看简历 → `/resume`；次：联系我 → 锚点/`mailto`）。背景极淡光晕。
- **关于**：2–3 行温度自述 + 状态徽章（如在招/城市），不重复简历页完整时间轴。
- **精选作品**：3 张项目卡（首图/字母占位 + 标题 + 标签 + 外链），底部"完整项目见简历 →"链接到 `/resume#projects`。
- **能力速览**：3–4 类核心技能 chips，hover 蓝边；"完整技能图谱见简历 →"。
- **快速链接**：图标 + 文字的纵向/网格链接列表，含简历页、GitHub、社交、外部博客。
- **联系 CTA**：整宽卡片，邮箱可复制 + 社交图标，巨号邀请语。

## 5. 简历子页（/resume）详细设计

### 5.1 定位

完整、专业、深度的履历。沿用 v2 已实现并验证的 **Bento Grid 苹果风** 布局，作为首页的"深度版本"。

### 5.2 结构（沿用，路由改为 /resume）

- Hero（大字号 + 求职徽章 + 双 CTA）
- 侧栏卡片：状态 / 数据 / 聚焦技术
- 关于（自述 + 时间轴）
- 技能（分类 chips）
- 经历（紧凑时间线列表）
- 项目（2 列 Bento 网格，hover 浮出按钮）
- 联系（整宽卡片）

> 具体内容规格与动效见 v2 文档，本版仅调整路由与导航链路（增加"返回首页"入口）。

## 6. 响应式设计（强制）

### 6.1 断点与适配

| 断点 | 宽度 | 首页策略 | 简历页策略 |
|------|------|---------|-----------|
| `sm` | ≥ 375px | 单列堆叠，Hero 字号收敛，触控 ≥44px | 单列，Bento 退化为单列 |
| `md` | ≥ 768px | 精选作品 2 列，导航展开 | Bento 2 列，侧栏上移 |
| `lg` | ≥ 1024px | 精选作品 3 列，Hero 双列（文字+monogram）| Bento 完整 6 列网格 |
| `xl` | ≥ 1440px | 内容最大宽度约束（max-w-6xl）| 同左 |

### 6.2 硬性规则（来自 ui-ux-pro-max 验收清单）

- [ ] 375 / 768 / 1024 / 1440px 四档均无明显错位
- [ ] **禁止横向滚动**（任何断点下 `overflow-x: hidden` 兜底）
- [ ] 触控目标 ≥ 44×44px
- [ ] 移动端 hover 效果改为 tap/active 触发
- [ ] 移动端导航折叠（汉堡菜单或底部栏）
- [ ] 图片/卡片不溢出视口

## 7. 内容规格

复用现有 `src/data/profile.ts`（Profile 模型不变）。首页新增少量"门面专属"字段（可选）：

```typescript

  monogram: 'Z',                 // 字母 monogram（无头像时）
  statusBadge: '开放新机会',      // 状态徽章
  featuredProjectIds: ['p1','p2','p3'], // 首页精选（引用 projects）
  quickLinks: [                  // 快速链接
    { label: '简历', href: '/resume', icon: 'file' },
    { label: 'GitHub', href: 'https://...', icon: 'github' },
  ],
}
```

> 简历页与首页共用同一份 Profile 数据，避免重复维护。

## 8. 非功能需求

### 8.1 性能

| 指标 | 桌面 | 移动 |
|------|------|------|
| FCP | < 1.8s | < 2.5s |
| LCP | < 2.5s | < 3.0s |
| CLS | < 0.1 | < 0.1 |
| Lighthouse Perf | ≥ 90 | ≥ 85 |

### 8.2 可访问性

- 对比度 WCAG AA（正文 4.5:1，大字 3:1）
- 所有交互元素 `focus-visible` 焦点环
- 非装饰图 `alt`；图标按钮带 `aria-label`
- `prefers-reduced-motion` 全量降级
- 键盘可遍历全部链接/按钮

### 8.3 SEO

- 每路由独立 `<title>` + `description` + Open Graph
- JSON-LD `Person`（简历页）+ `WebSite`（首页）
- `sitemap.ts` 含 `/`、`/resume`、`/creative`

## 9. 技术约束（摘要，详见技术文档）

- 框架：Next.js（App Router）+ TypeScript + Tailwind CSS v4 + framer-motion + lucide-react
- 渲染：纯 SSG（3 路由静态生成）
- 设计令牌：globals.css CSS 变量，首页/简历页共享
- 字体：`next/font` 加载 Inter / Space Grotesk / JetBrains Mono
- 动画：framer-motion 滚动驱动 + CSS 过渡；Canvas 仅创意版使用
