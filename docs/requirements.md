# 个人站点 — 需求文档（国风数字简历）

> 版本：v2.0  
> 最后更新：2026-07-24

---

## 1. 项目重新定位

### 1.1 一句话定义

> **一页到底的国风数字简历**——用东方美学与动态视觉叙事，让 HR 在 30 秒内记住你。

### 1.2 核心问题

传统 PDF 简历 HR 平均看 6 秒就划走。我们需要一个"简历即作品"的页面：
- 它不是信息列表，而是一次**视觉体验**
- 它不是白纸黑字，而是一场**国风叙事**
- 它不止展示技能，更展示**品味与执行力**

### 1.3 目标用户（重新聚焦）

| 用户角色 | 场景 | 核心诉求 |
|---------|------|---------|
| HR / 猎头 | 收到链接 → 打开页面 | 第一眼被打动，想看下去 |
| 技术面试官 | HR 转发 → 评估能力 | 快速判断技术栈匹配度 |
| 团队 Leader | 筛选候选人 | 感受审美、工程能力、项目经验 |
| 同行开发者 | 口口相传 | "这哥们页面有点东西" |

### 1.4 成功指标

- 平均停留时长 > 40 秒（传统简历页面平均 < 15 秒）
- HR 转发率（页面被再次分享的比例）
- 移动端体验不打折（面试官很可能在手机上打开）

## 2. 页面结构：一页到底

整个站点只有**一个页面**，通过滚动叙事串联所有内容。导航只做锚点平滑滚动，不做页面跳转。

### 2.1 页面分区（自上而下）

```
┌──────────────────────────────────────┐
│  #1 首屏 · 英雄区 (Hero)              │  ← 100vh，全屏沉浸
│  姓名 · 角色 · 一句话                 │
│  国风背景动画                          │
├──────────────────────────────────────┤
│  #2 关于我 (About)                    │  ← 个人简介 + 经历时间轴
│  自述文案 · 工作/教育经历             │
├──────────────────────────────────────┤
│  #3 技能展示 (Skills)                 │  ← 技能图谱/雷达/云图
│  技术栈可视化                          │
├──────────────────────────────────────┤
│  #4 项目作品 (Projects)               │  ← 项目卡片，外链跳转
│  精选项目展示 + 外链                   │
├──────────────────────────────────────┤
│  #5 联系我 (Contact)                  │  ← 联系方式 + CTA
│  邮箱 · 社交链接 · 二维码（可选）       │
└──────────────────────────────────────┘
```

### 2.2 导航设计

顶部固定导航栏，半透明毛玻璃质感，右对齐：

| 导航项 | 锚点目标 | 说明 |
|--------|---------|------|
| 关于 | `#about` | 平滑滚动 |
| 技能 | `#skills` | 平滑滚动 |
| 项目 | `#projects` | 平滑滚动 |
| 联系 | `#contact` | 平滑滚动 |

- 导航栏滚动时背景加深（`backdrop-blur` 渐变）
- 当前可视区域对应的导航项高亮
- 移动端折叠为汉堡菜单

## 3. 各分区详细设计

### 3.1 英雄区 (Hero) — 第一印象决定一切

**目标**：3 秒内建立"这人不一样"的第一印象。

**内容元素**：
- 大号姓名（毛笔书法风格字体或描边粗体）
- 角色定位（如"全栈工程师 / 开源贡献者"）
- 一句话 tagline（如"以代码写诗，以架构作画"）
- 向下滚动提示箭头（脉动动画）

**背景设计**：
- 国风水墨山水动态背景（SVG / Canvas / WebGL）
  - 山峦层叠、云雾流动
  - 或：粒子构成的水墨笔触动画
- 色调：以墨色为底，留白为主

**动态效果**：
- 背景山脉/云雾缓慢平移（视差）
- 文字逐字浮现（typewriter 或逐字淡入）
- 鼠标移动时背景轻微跟随（视差微交互）
- 滚动时背景层以不同速率移动（多层视差）

### 3.2 关于我 (About) — 让人想认识你

**内容元素**：
- 个人自述（100–150 字，口语化、有温度）
- 工作经历时间轴（左对齐或交替排列）
  - 公司 · 职位 · 时间 · 关键成果（1–2 行）
- 教育背景

**设计语言**：
- 背景过渡：从墨色渐变为宣纸色（米白 / 淡黄）
- 时间轴用毛笔笔触线条连接
- 文字排版：竖排或半竖排元素点缀（印章、批注红点）

**动态效果**：
- 滚动到该区域时，时间轴节点逐个亮起（描边动画）
- 经历卡片从两侧滑入
- 印章元素旋转出现

### 3.3 技能展示 (Skills) — 一图胜千言

**内容元素**：
- 核心技术栈，按类别分组：
  - 语言、前端、后端、基础设施、工具
- 每个技能标注熟练度（熟练 / 精通）

**可视化方案（三选一或组合）**：
1. **技能雷达图**（Canvas/SVG）：多条轴线，国风配色
2. **技能气泡云**：不同大小气泡，hover 放大 + 显示详情
3. **技能卷轴展开**：模仿古画卷轴，从左到右展开展示

**动态效果**：
- 滚动到区域时整体触发动画
- 雷达图从 0 展开到满值
- 气泡逐个浮现，带弹性动画
- hover 时气泡放大 + 涟漪效果

### 3.4 项目作品 (Projects) — 作品说话

**内容元素**：
- 3–5 个精选项目卡片
- 每个卡片包含：
  - 项目名 + 一句话描述
  - 技术标签
  - 项目缩略图 / 示意插画
  - **外链按钮**（GitHub / 线上 Demo）

**重要**：不设项目详情页，点击直接跳转外部链接。保持单页完整性。

**设计语言**：
- 卡片排列：横向滚动或瀑布流
- 卡片边框：水墨晕染风格（羽化边缘 / 撕纸效果）
- hover 时卡片微微抬起 + 阴影加深

**动态效果**：
- 卡片从底部淡入上浮（stagger 延迟）
- hover 时项目截图放大（clip-path 揭示动画）
- 外链按钮 hover 有墨点扩散效果

### 3.5 联系我 (Contact) — 降低联系门槛

**内容元素**：
- 邮箱（可复制）
- GitHub / 掘金 / LinkedIn 图标链接
- 微信二维码（可选，hover 显示）
- 一句话 CTA："期待与你交流"

**设计语言**：
- 收尾区域，色调回归深邃（呼应首屏）
- 底部印章落款："××× 敬上"

**动态效果**：
- 社交图标 hover 旋转 + 发光
- 邮箱点击复制后弹出"已复制"提示（毛笔笔触样式）

## 4. 国风设计语言规范

### 4.1 色彩体系

| 角色 | 色值 | 用途 |
|------|------|------|
| 墨色（深） | `#1a1a1a` ~ `#2d2d2d` | 主文字、深色背景 |
| 墨色（浅）| `#4a4a4a` ~ `#666666` | 辅助文字 |
| 宣纸色 | `#f5f0e8` / `#faf6f0` | 浅色背景主色 |
| 朱砂红 | `#c41e3a` / `#b22222` | 强调色、印章色、CTA 按钮 |
| 金色点缀 | `#c9a96e` / `#b8860b` | 边框、分割线、hover 高亮 |
| 青蓝 | `#2c5f7c` / `#3a7ca5` | 链接色、图标色 |
| 留白 | `#ffffff` | 卡片、区间背景 |

**深浅模式**：浅色模式以宣纸色打底，深色模式以墨色打底，朱砂红在两种模式下均为强调色。

### 4.2 字体体系

| 用途 | 字体 | 说明 |
|------|------|------|
| 标题（大） | 思源宋体 / Noto Serif SC | 有书法韵味，Hero 区名字用 |
| 标题（小） | 站酷小薇 / ZCOOL XiaoWei | 国风手写感 |
| 正文 | 思源黑体 / Noto Sans SC | 现代可读性 |
| 代码 / 数据 | JetBrains Mono | 技能标签、技术名词 |
| 印章文字 | 方正篆体（图片替代） | 装饰性印章 |

字体加载策略：
- 宋体和黑体优先使用系统已安装版本（`font-family` fallback）
- Web 字体按需子集化加载，控制体积 < 100KB
- 印章用 SVG/PNG 图片，不依赖字体

### 4.3 视觉元素

| 元素 | 说明 |
|------|------|
| 印章 | 红色圆章/方章，用于落款、认证标记 |
| 水墨笔触 | 分割线、卡片边框、背景装饰 |
| 云纹 | SVG 背景装饰，淡色循环移动 |
| 山峦剪影 | Hero 区背景层叠山峰 |
| 梅花/竹叶 | 点缀装饰（粒子效果） |
| 卷轴 | 技能或项目区域载体（可选） |

### 4.4 动效原则

> **动效服务于叙事，不为炫而炫。**

- 所有动画基于滚动触发（Intersection Observer）
- 动画时长控制在 300–800ms，不拖沓
- 入场动画只播放一次，回到区域不重播（除非刷新页面）
- 尊重 `prefers-reduced-motion`：减弱动效用户关闭复杂动画
- 移动端适当缩减动效复杂度（硬件限制）

## 5. 动态效果详细规格

### 5.1 Hero 区 — 背景水墨山水

```
技术方案：CSS 多层视差 + SVG/Canvas 粒子

层 1（远景）：山峰剪影 SVG，缓慢平移，速度 0.2x 滚动
层 2（中景）：云雾 PNG/SVG，左右漂浮，速度 0.4x 滚动
层 3（近景）：松枝/屋檐剪影，速度 0.6x 滚动
层 4（前景）：文字内容，正常滚动

额外：Canvas 墨点粒子，随机生成、缓慢下落、淡出
```

### 5.2 文字入场动画

```
Hero 标题：逐字淡入 + 上浮（stagger 80ms/字）
Hero 副标题：标题动画完成后 300ms，整句淡入
Tagline：副标题完成后 200ms，打字机效果逐字出现
```

### 5.3 滚动驱动动画

```
方案：framer-motion useScroll + useTransform

#about 区域：
  - 时间轴描边动画（SVG stroke-dasharray 从 0 到完整）
  - 经历卡片左右滑入（奇数左、偶数右）

#skills 区域：
  - 雷达图从圆心向外扩展（scale + opacity）
  - 技能标签逐个弹入（spring 弹性动画）

#projects 区域：
  - 卡片 stagger 上浮（y: 40 → 0, opacity: 0 → 1）
  - 每张卡片延迟 150ms

#contact 区域：
  - 图标 scale 弹入（stagger 100ms）
```

### 5.4 微交互

| 交互 | 效果 |
|------|------|
| 鼠标移动（Hero）| 山脉层轻微跟随（mousemove 驱动 translate）|
| hover 技能标签 | 标签放大 1.1x + 金色边框 + 墨点涟漪 |
| hover 项目卡片 | 卡片上浮 8px + 阴影加深 + 图片 clip-path 展开 |
| hover 导航链接 | 下方金色墨线从左到右划入 |
| hover 社交图标 | 旋转 15° + 朱砂红发光 |
| 点击邮箱 | 复制到剪贴板 + toast 提示"已复制" |
| 滚动到底部 | 出现"回到顶部"浮动按钮（毛笔箭头） |

## 7. 非功能需求

### 7.1 性能（动画密集型页面）

考虑到大量动效，性能要求适当放宽但仍需达标：

| 指标 | 桌面端目标 | 移动端目标 |
|------|-----------|-----------|
| FCP | < 2.0s | < 2.5s |
| LCP | < 3.0s | < 3.5s |
| TBT | < 300ms | < 500ms |
| CLS | < 0.1 | < 0.15 |
| Lighthouse Perf | ≥ 80 | ≥ 70 |

### 7.2 动画性能约束

- 所有动画使用 GPU 加速属性（`transform`、`opacity`），禁止动画 `width/height/top/left`
- Canvas 粒子数量控制在 200 以内
- `requestAnimationFrame` 节流：非激活标签页暂停动画
- 图片使用 WebP 格式，项目截图压缩至 < 200KB
- `prefers-reduced-motion` 媒体查询：关闭所有非必要动画

### 7.3 兼容性

- 桌面端：Chrome / Firefox / Safari / Edge 最近两个大版本
- 移动端：iOS Safari / Android Chrome 最近两个大版本
- Canvas / WebGL 效果在低端设备上有降级方案（纯 CSS 替代）

### 7.4 SEO

虽然是单页面，仍需：
- 页面 `<title>` + `<meta description>`
- Open Graph 标签（分享到微信/微博时展示卡片）
- 结构化数据 `Person` Schema（JSON-LD）
- `sitemap.xml`（单页也要有）

### 7.5 可访问性

- 非装饰性图片提供 `alt` 文本
- `prefers-reduced-motion` 支持
- 颜色对比度符合 WCAG AA 标准
- 键盘导航可用（Tab 键遍历链接）

## 8. 技术约束（动画相关）

本节为需求文档中的技术约束，供技术实现文档参考。

### 8.1 动画库选择

| 场景 | 推荐方案 | 原因 |
|------|---------|------|
| 滚动驱动动画 | framer-motion `useScroll` | React 生态最成熟的滚动动画方案 |
| 入场动画 | framer-motion `whileInView` | 原生滚动触发支持 |
| Canvas 粒子 | 自写 Canvas + requestAnimationFrame | 轻量可控，不引入额外依赖 |
| SVG 描边动画 | CSS `stroke-dasharray` + `stroke-dashoffset` | 纯 CSS，GPU 友好 |
| CSS 过渡/微交互 | Tailwind + CSS transition | 日常交互无需 JS |

### 8.2 国风元素的实现路径

| 元素 | 实现方式 |
|------|---------|
| 山脉剪影 | SVG path，多层叠加，CSS `transform` 驱动视差 |
| 云雾效果 | 多个半透明 SVG blob，CSS animation 循环漂移 |
| 印章 | SVG 内嵌文字路径 + 朱砂红填充 |
| 墨点粒子 | Canvas 2D，随机圆形，带透明度渐变 |
| 卷轴 | CSS clip-path 展开 + 渐变模拟 |
| 毛笔笔触分割线 | SVG/PNG 图片 + CSS scaleX 动画 |

### 8.3 动画开关

页面提供一处隐蔽的动画开关（如底部"动画：开/关"），供：
- 动画敏感用户关闭
- 低性能设备自动关闭
- 开发调试时手动切换
